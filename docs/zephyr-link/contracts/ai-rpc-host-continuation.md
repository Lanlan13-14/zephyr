Cell/One-sandbox/local-code-execution and RDP/VNC execution targets are rejected. `ai.approval.request`, `ai.cell.pty.frame`, the global production vector coverage and true device UI acceptance are not claimed.

[KNOWN] SQLite reserves stable account/device/binding/request ID before dispatch. Only input hashes and minimal run receipts persist; not prompts/provider keys/SSE tickets. Duplicate/in-flight input replays one run. Changed input conflicts. Reboot with a reserved or uncertain dispatch never repeats it, and old runtime generations cannot execute again under that ID. Ambiguous failures require query, never automatic redispatch. This is safety-first at-most-once, not a promise of crash-transparent exactly-once liveness.

[KNOWN] Strict Link runs force ask for every tool and disable auto-confirm in Node and Go. The strict bit survives paused/resumed runs, so an older generic permission endpoint cannot bypass it. Approval preview binds current run/session/call/tool arguments and runtime generation/nonce hash. Two-minute device P1363 proof binds request ID, original run, approval ID, input hash, approve/deny, challenge and expiry. Old challenges are consumed before runtime restore. SQLite CAS consumes exact paused JSON before tools resume; failure/crash does not resurrect approval. Input changes invalidate approval.

[KNOWN] Identity and policy are rechecked before side effects and before returning state. Database replacement tracks/drains the private AI request through the same maintenance barrier. Replay is at most 200 events/1 MiB with monotonic cursor; provider credentials are reinjected only from the canonical current owner-scoped resolver.
